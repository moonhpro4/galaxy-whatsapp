# Galaxy WhatsApp (unofficial)

Loads web.whatsapp.com in its own window.

- **Ctrl + Alt + F3** (while the app is open) opens Developer Mode: set / change / remove a PIN, launch at startup, lock now.
- With a PIN set, a PIN screen appears before WhatsApp loads.

## Get the installer (.exe with setup wizard)
**Option A – GitHub (no tools needed):** push this repo; open the *Actions* tab, click the latest run, and download **Galaxy-WhatsApp-Setup** (a zip containing the .exe).

**Option B – Windows PC:** install Node.js 20+, then `npm install` and `npm run build`. Installer is in `dist\`.

Test without installing: `npm install` then `npm start`.
